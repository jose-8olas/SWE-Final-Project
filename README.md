# Low-Stock Detection Pipeline

## Project Description

A Python-based inventory analysis prototype that
identifies low-stock products and generates reorder
recommendations using inventory and sales data.

## Main Features

- CSV inventory input
- Inventory data validation
- Low-stock detection
- Reorder quantity calculations
- AI-generated explanations
- Store Manager recommendation review

## Technologies

- Python
- CSV
- Git and GitHub
- LLM API (planned)

## Project Status

Currently in development.
